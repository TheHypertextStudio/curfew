Open **Schedule** to set when work ends and resumes each day.

![The Schedule view shows per-day Work ends and Work resumes times, Day off switches, and Time, Hours, or Both triggers.](/images/schedule.png)

## Set a work window

1. Start from a preset, or edit a day in **Weekly Schedule**.
2. Set **Work ends** to your stopping time.
3. Set **Work resumes** to the time you can use the Mac again.
4. Turn on **Day off** for days off. Use **Apply to all** to copy a day's rule.
5. Read the schedule summary and any **Pending Change** message.

Work ending at 6 PM and resuming at 9 AM creates an overnight boundary.

## Choose what triggers lockout

The **Trigger** control offers a fixed stopping time, an hours limit, or both.
With both, reaching either limit ends your session. Check **Today** for the
next boundary.

## When changes take effect

| Change | Earliest application |
| --- | --- |
| Later stopping time, earlier resume time, or adding a day off | After a 24-hour cooldown |
| More restrictive schedule without loosening another day | At the start of the next calendar day |
| Changing the trigger mode | After a 24-hour cooldown |

An edit that loosens one day and tightens another uses the 24-hour cooldown.
During lockout, more permissive changes wait until access resumes.

Check **Pending Change** for the application time. For extra time today, use
an available [extension or override](/exceptions).
