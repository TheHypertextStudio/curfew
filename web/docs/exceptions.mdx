---
title: Extensions and emergency overrides
description: Request more time before lockout or deliberately regain temporary access after it begins.
---

Set weekly extension and override budgets in **Settings → Lockout**.

| | Extension | Emergency override |
| --- | --- | --- |
| When | Before lockout, when the extension action is available | During lockout |
| Result | Pushes back the stopping time | Temporarily restores access |
| Confirmation | Hold the extension button | Write a reason, wait through a cooldown, then hold to confirm |

## Request an extension

1. Check **Today** or the warning screen for the extension action and remaining
   budget.
2. Read the duration on the button.
3. Hold it for the displayed time until confirmation completes.
4. Check that the stopping time moved and your remaining budget decreased.

Extensions require available weekly budget.

## Use an emergency override

1. On the lockout screen, choose **Need to get back in?**.
2. Write a reason of at least **50 characters** explaining why you need access.
3. Wait for the **five-minute cooldown**.
4. Read the access duration and budget consequence, then hold the confirmation
   button for **three seconds**.

When granted, the override consumes one available override and is recorded in
your activity. Lockout resumes when temporary access ends. Overrides require
available weekly budget.

## Set budgets before you need them

Open **Settings → Lockout**. Choose weekly
limits, extension duration, override duration, and **Resets on**.

An assistant can request supported changes under your [consent policy](/mcp-guide).
Complete emergency overrides on the lockout screen.
