---
title: Connect an AI assistant
description: Connect Claude Desktop or another compatible assistant, choose its permissions, and check that it works.
---

Connect an assistant to ask about your schedule, plan around your stopping
time, or review reflections. Curfew connects through **MCP**. For remote assistants, start with
[account setup](/accounts) and review the requested permissions.

## Connect Claude Desktop on this Mac

1. Install and open Claude Desktop, and complete [Curfew setup](/install).
2. Open **Curfew → Settings → Connections**.
3. Turn on **Allow assistants on this Mac**.
4. Leave **Changes** on **Ask before making changes**.
5. Click **Add to Claude Desktop**, then fully quit Claude with **⌘Q** and reopen it.
6. In Claude, ask: **“What is my Curfew schedule?”** Compare the answer with Curfew.

If **Add to Claude Desktop** is missing, check that Claude Desktop is installed.
Use the copy-config option below for other compatible assistant apps.

## Decide what the assistant may change

| Policy | What happens |
| --- | --- |
| Ask before making changes | Changes wait for you to review them in Curfew. |
| Allow changes automatically | Supported requests can take effect without an approval prompt. Only use this with a client you trust. |
| Read only | The assistant can read available information but cannot request changes. |

Requests follow Curfew's schedule rules and budgets. Complete emergency
overrides on the lockout screen.

Try **“How long until my stopping time?”** or **“Summarize my reflections from
this week.”** Check requested changes in Curfew.

The assistant's countdown uses the saved schedule, excluding
temporary extensions or active overrides. Check **Today** for current
enforcement and hours-based limits.

<Warning>
Connected assistants can read saved reflections and send them to their
provider. Review the provider's privacy settings before connecting.
</Warning>

## Connect another compatible app

Use **Manual setup → Copy Configuration** in **Settings → Connections** to get the
correct path to your installed app. Follow your assistant's instructions for
adding a local MCP server. For Claude Desktop, the configuration file is
`~/Library/Application Support/Claude/claude_desktop_config.json`.

Add Curfew to the existing `mcpServers` section. For an app in Applications:

```json
{
  "mcpServers": {
    "curfew": {
      "command": "/Applications/Curfew.app/Contents/Resources/curfew-mcp",
      "args": []
    }
  }
}
```

## Disconnect or troubleshoot

Remove Curfew's server entry from the assistant's configuration or connected
tools, then fully quit and restart the assistant. Also turn off **Allow assistants on this Mac** in Curfew to stop the app from handling integration requests.
Locally configured assistants can still read saved schedules and reflections
while the toggle is off. Manage retained copies through the provider's privacy
settings.

If tools do not appear during setup, fully quit and reopen the assistant and
check the configured app path. For pending or denied requests, check the
consent policy and keep Curfew running so you can review requests.
