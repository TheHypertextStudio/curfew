Curfew is a macOS commitment device: set a schedule, and when the clock runs out
your Mac locks you out. These docs cover the **developer-facing** surfaces, not
end-user help.

## How it fits together

The macOS app holds all enforcement logic and verifies licenses **offline** with
an embedded Ed25519 public key. The only networked component is the **license
Worker**, which signs keys on Stripe webhooks and delivers them to the buyer.
Curfew Plus iCloud sync runs on CloudKit (Apple-managed, no custom endpoints).

<Note>
The API reference is generated from the Worker's route definitions
(`@hono/zod-openapi`), so it can't drift from the implementation. This guide set
is the narrative layer on top of it.
</Note>
