title: Use Calendar
description: Show today's calendar events alongside Curfew.

<Note>
Calendar is not available yet. It will require an active Plus license.
</Note>

Calendar shows today's events on the lockout screen and in **This Week**.

## Grant access

1. [Activate Plus](/licensing), then open **Settings → Connections**.
2. Find **Calendar** and choose **Allow Calendar Access…**.
3. Review the macOS permission prompt and allow access if you want Curfew to
   read events.
4. Return to Curfew and check for **Today's events**.

If access was denied, open **System Settings → Privacy & Security → Calendars**,
allow Curfew, and return to the app. Revoke the permission in the same place.

## Plan around a late meeting

Check events before the workday. Plan a [schedule change](/schedules) far enough
ahead for its cooldown, or decide whether to use an available
[extension](/exceptions).

## If events are missing

Check that the event appears in the Mac's Calendar app for today and Curfew
has Calendar access. If the panel is missing, check whether your version
includes the feature.
