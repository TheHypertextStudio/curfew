Check your app version in **Settings → About** and status in **Today**.

## Setup will not continue

In the first step, choose **Use this schedule** or **No schedule yet** to
continue. The second step requires Accessibility access. Choose **Open System
Settings** and drag the Curfew icon from the small panel into the list, or turn
on **Curfew.app** if it is already listed. macOS calls this **Device Control and
Data Access**, or **Accessibility** on versions that use that name. Curfew Dev
is a separate build. macOS may ask for Touch ID or an administrator password.
Setup moves on by itself once access is granted. Notifications and the Curfew
helper are optional.

Resume setup through **Settings → Protection → Continue Setup…**.
Use **General** in earlier versions.

## Lockout or keyboard blocking is not working

Open **Settings → Protection**. Use the repair action for missing Accessibility
access. If **Background recovery** needs approval, open **System Settings →
General → Login Items & Extensions** and allow Curfew. macOS may ask for Touch ID
or an administrator password to allow background activity for all users.
Check that background recovery is enabled. If **Background protection** is not
connected, use its connection action and complete the macOS approval. Read any
error shown before trying again.

If enforcement remains degraded after updating, send support the status text
and app version.

## My schedule edit did not apply

Check **Schedule → Pending Change**. More permissive edits wait 24 hours;
stricter edits apply at the next day boundary. More permissive edits also
wait until an active lockout ends. See [schedule rules](/schedules).

## I need access during lockout

Use **Need to get back in?** on the lockout screen. You need an available
override, a reason, a cooldown, and a hold to confirm. See
[extensions and emergency overrides](/exceptions).

## The assistant cannot find Curfew or a request stays pending

Check **Allow assistants on this Mac** in **Settings → Integrations**, fully quit
and reopen the assistant, and confirm its configuration points to Curfew's
installed path. Keep Curfew open to review requests. **Read only**
blocks changes. See [assistant setup](/mcp-guide).

## Plus will not activate or a feature is missing

Install the [latest Curfew release](https://thecurfew.app/download) to use
activation and restore links.
If you lost your confirmation page or key,
[restore your purchase](https://thecurfew.app/restore) using the email address
on your receipt. See [activation troubleshooting](/licensing#activation-or-delivery-problems).

Sync and Calendar are not available yet.

## Ask for help

Email [support@thecurfew.app](mailto:support@thecurfew.app) with:

- Your macOS version and Curfew version from **Settings → About**.
- What you tried, what happened, and the exact error.
- Whether it started after an update or permission change.
- For purchases, your checkout email and receipt or order details.

Remove keys, private reflections, calendar details, and other personal
information from screenshots.
