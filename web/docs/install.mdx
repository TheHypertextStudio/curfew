---
title: Install and set up Curfew
description: Install Curfew on macOS, choose your first schedule, and grant the permissions needed for lockout.
---

You need **macOS 26 or later**. A public Mac installer has not been released yet.
Check the [download page](https://thecurfew.app/download) for availability.
Save your work before starting setup.

## Install the app

When an installer is available:

1. Download Curfew from the [download page](https://thecurfew.app/download).
2. Open the disk image and drag **Curfew** into **Applications**.
3. Open Curfew from Applications and follow **Welcome to Curfew**.

![Curfew's Welcome screen introduces the setup walkthrough and its Next button.](/images/setup.png)

## Choose your first boundary

1. In the **Schedule** setup step, click **Open Schedule**.
2. Set when work ends and resumes for each active day, and mark days off.
   See [schedule settings](/schedules).
3. Return to Getting Started and choose your weekly extension and override limits.
4. Continue to **Permissions**.

## Grant permissions

**Accessibility is required.** Curfew uses it to keep the lockout screen in
place and intercept dismissal shortcuts. Follow the setup button to
**System Settings → Privacy & Security → Accessibility**, enable Curfew, then
return to the app.

**Notifications are optional.** Allow them for early warnings before lockout.

See [privacy and permissions](/privacy) for other permissions.

## Review and enable

Read the schedule summary on **Confirmation**, then finish setup when ready.
Curfew starts enforcing your schedule. Check **Today** for your status and
next boundary.

<Warning>
If your schedule is outside its permitted work window, enabling Curfew can
start lockout. Save your work before finishing setup.
</Warning>

Open **Settings → General → Continue Setup…** to resume setup, or
**Review Setup…** after completing it.
Change boundaries in **Schedule**, and warnings and exception budgets in
**Settings → Limits**.

If setup will not continue, follow [setup troubleshooting](/troubleshooting).
