---
title: Install and set up Curfew
description: Install Curfew on macOS, choose your first schedule, and grant the permissions needed for lockout.
---

Curfew requires **macOS 26 or later**. Check the
[download page](https://thecurfew.app/download) for availability, then save your
work before setup.

## Install the app

1. Download Curfew from the [download page](https://thecurfew.app/download).
2. Open the disk image and drag **Curfew** into **Applications**.
3. Open Curfew from Applications and follow **Welcome to Curfew**.

For Curfew Plus, follow the [activation and restore instructions](/licensing).

![Curfew's Welcome screen introduces the setup walkthrough and its Next button.](/images/setup.png)

## Choose your first boundary

1. In the **Schedule** setup step, click **Edit weekly schedule**.
2. Set when work ends and resumes for each active day, and mark days off.
   See [schedule settings](/schedules).
3. Review all seven days, including days off. Choose
   **I've reviewed these seven days — use this weekly schedule** to enable
   scheduled lockouts, or **No automatic schedule — remote controls only**
   to leave automatic lockouts off. Authorized remote locks can still apply.
4. Choose your weekly extension and override limits, then continue to **Permissions**.

## Grant permissions

**Accessibility is required.** Curfew uses it to block dismissal
shortcuts during lockout. Follow the setup button to
**System Settings → Privacy & Security → Accessibility**, enable Curfew, then
return to the app.

**Notifications are optional.** Allow them for early warnings before lockout.

See [privacy and permissions](/privacy) for other permissions.

## Review and enable

Read the schedule summary on **Confirmation**. If you selected weekly lockouts,
choose **Enable schedule and finish** when ready. With remote controls only,
finishing setup leaves automatic lockouts off. Check **Today** for your status
and next boundary.

<Warning>
Enabling a schedule outside its permitted work window can start lockout.
Curfew asks for a separate confirmation when lockout is imminent. Save your
work before enabling weekly lockouts.
</Warning>

Open **Settings → Protection → Continue Setup…** to resume setup, or
**Review Setup…** after completing it.
Use **General** in earlier versions.
Change boundaries in **Schedule**, warnings in **Settings → Lockout**, and
exception budgets in **Settings → Lockout**.

If setup will not continue, follow [setup troubleshooting](/troubleshooting).
