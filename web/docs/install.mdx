---
title: Install and set up Curfew
description: Install Curfew on macOS, choose your first schedule, and grant the permissions needed for lockout.
---

Curfew requires **macOS 26 or later**. Check the
[download page](https://thecurfew.app/download) for availability, then save your
work before setup.

## Install the app

1. Download Curfew from the [download page](https://thecurfew.app/download).
2. Open the disk image and drag **Curfew** into **Applications**.
3. Open Curfew from Applications. Setup opens by itself and takes three steps.

For Curfew Plus, follow the [activation and restore instructions](/licensing).

![Curfew's setup window opens on its first step.](/images/setup.png)

## Step 1: choose your curfew

Setup asks **When should this Mac close for the night?** Set the curfew time,
the unlock time and the days that lock. They start from the current default
schedule. Choose **Use this schedule** to turn on scheduled locks, or the small
**No schedule yet** link to leave automatic locks off. Authorized remote locks
can still apply. You can change times and days later in
[schedule settings](/schedules).

## Step 2: let Curfew hold the lock

Each item says why it is needed and shows its current state.

**Accessibility is required.** Curfew uses it to block dismissal shortcuts
while this Mac is locked. Choose **Open System Settings**. A small panel opens
beside System Settings with the Curfew icon: drag it into the list. macOS may
ask for Touch ID or an administrator password. If Curfew is already listed,
turn it on. macOS calls this **Device Control and Data Access**, or
**Accessibility** on versions that use that name. Curfew Dev is a separate
build. Setup moves on by itself the moment access is granted.

**Notifications are optional.** Choose **Allow** to hear about curfew 30, 15, 5
and 1 minute ahead. Curfew does not ask again after setup.

**The Curfew helper is optional.** Choose **Install** so the lock holds even if
Curfew is quit; macOS asks for an administrator password. Without it, force
quitting Curfew ends the lock early. You can install it later in
**Settings → Protection**, where **Background recovery** and **Background
protection** show its current state.

<Warning>
  If your curfew has already started, Curfew asks you to confirm before setup finishes, because
  finishing locks this Mac right away. Save your work first.
</Warning>

## Step 3: you're set

Setup states when Curfew locks next, such as tonight at your curfew time.
**Preview the lock** shows the lock for a few seconds; nothing locks, and
**End preview** or Escape closes it.

Two optional extras follow: **Sign in to sync** and **Get the lifetime
licence**. **Skip** closes setup and opens **Today**.

If you close setup early, it opens again at the same step the next time Curfew
starts.

Open **Settings → Protection → Continue Setup…** to resume setup, or
**Review Setup…** after completing it.
Use **General** in earlier versions.
Change your curfew in **Schedule**, warnings in **Settings → Lockout**, and
exception budgets in **Settings → Lockout**.

If setup will not continue, follow [setup troubleshooting](/troubleshooting).
