---
title: Sync your Macs
description: Use the same Curfew schedule on your Macs and check whether iCloud has finished syncing.
---

<Note>
iCloud sync is not available yet. It will require an active Plus license.
</Note>

Each Mac needs a version that supports iCloud sync, an active Plus license,
and the same Apple Account signed in to iCloud. Sync requires an internet connection.

## Set up each Mac

1. Install the supported Curfew release and complete setup on each Mac.
2. [Activate Plus](/licensing) on each one.
3. In macOS System Settings, confirm the same Apple Account is signed in and
   iCloud is available on each Mac.
4. Open **Curfew → Settings → Account** and check **iCloud Sync**.
5. Wait for **Last synced**, then compare the active schedule on your Macs.

Sync runs automatically. **Devices** shows each Mac's last reported activity.

## While a Mac is offline

An offline Mac uses its saved schedule and receives updates when it reconnects.
Check **Last synced** on each Mac after changing your schedule.

Schedule changes follow the [cooldown rules](/schedules). Written reflection
answers stay on each Mac.

## If sync is not working

- **No iCloud Sync panel:** check that your Curfew version supports the feature.
- **iCloud unavailable:** sign in to iCloud in System Settings on that Mac.
- **Sync failed:** check the connection and displayed error, then reopen Curfew.
- **One Mac is missing or stale:** open Curfew on it, reconnect, and wait for a
  successful sync report.

If schedules still differ after successful sync, contact
[hello@hypertext.studio](mailto:hello@hypertext.studio) with both app versions
and sync messages. Keep license keys and journal entries private.
