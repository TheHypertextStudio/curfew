Curfew setup, three approaches

Three ways to start.

Each one opens with a welcome, puts one thing on each screen and keeps the action in the same place. They differ in how Curfew introduces itself and how it asks for the schedule. All three ask for the same things under the same rules, then offer Curfew Plus once and open Today.

Recommendation: See it first

The welcome answers "what is this" by showing the thing itself, so every later screen can stay short. It asks one question before the permission. The motion sits where it explains something and nowhere else. One thing at a time is the safer fallback if the intro feels like too much.
