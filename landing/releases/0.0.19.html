Curfew 0.0.19

Curfew’s command line beta adds a Homebrew install path and more ways to work from Terminal.

Install the command line

Homebrew installs Curfew and puts curfew-ctl and curfew-mcp on PATH.

brew install --cask thehypertextstudio/tap/curfew

If you already installed Curfew with Homebrew, run this command to upgrade.

brew upgrade --cask thehypertextstudio/tap/curfew

If you downloaded Curfew directly, open Settings → Integrations and choose Install command line tool. Review the changes, choose Install, and open a new Terminal.

Use the beta commands

Read your schedule, budget, activity, reflections, and audit events. Request an extension or a time-based schedule change and check the approval result with curfew-ctl request status. Curfew applies its existing approval rules and schedule cooldowns.

JSON output now uses schema version 1. Scripts can find lists under named fields, decisions under request_status, and durations in seconds. The beta command guide lists the changes and examples.

Update Curfew

Curfew requires macOS 26 or later. Keep your existing app data so your schedule, history, and preferences remain available.
