Curfew 0.0.21

Curfew’s command line is in beta. This release fixes how Curfew recovers approved schedule changes after a restart.

Recover schedule requests

If Curfew restarts before it reports an approved schedule request, it now reports the original approval without applying the change again or replacing a newer schedule. Run curfew-ctl request status to check the result.

Curfew asks you to review schedule requests that were still pending when you updated from an earlier version. Check your current schedule before submitting a new request.

Install or update the command line

Homebrew installs Curfew and puts curfew-ctl and curfew-mcp on your PATH.

brew install --cask thehypertextstudio/tap/curfew

If you installed Curfew with Homebrew, run this command to upgrade.

brew upgrade --cask thehypertextstudio/tap/curfew

If you downloaded Curfew directly, open Settings → Integrations and choose Install command line tool.

Curfew requires macOS 26 or later. See the CLI beta guide for commands and examples.
