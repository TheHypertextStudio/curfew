MCP server — free

AI assistants can read your state and negotiate extensions from within a coding session.

Claude can negotiate with your focus rules.

curfew-mcp is a stdio MCP server bundled with the app. Add it to Claude Desktop in one click and your AI assistant can check how much time you have left, request an extension, or start a focus session — all with your approval. 

{
  "mcpServers": {
    "curfew": {
      "command": "/Applications/Curfew.app/Contents/Resources/curfew-mcp",
      "args": []
    }
  }
}

Or copy the config snippet directly from Settings → Integrations.
