Curfew GitHub

Work has an
end time.

Set your work hours. Curfew gives you a countdown when the day is over, then puts a full-screen lockout in the way. You can also have it shut your Mac down.

See how it works

Set it once. Let it do its job.

01

Set your hours

Choose start and stop times for each day, days off, or an hours-based schedule. Changes close to curfew wait for a cooldown.

02

Get a heads-up

Curfew counts down at 30, 15, 5, 2, and 1 minutes.

03

Call it a night

At curfew, a full-screen lockout appears. Automatic shutdown is optional.

Need more time? Write a reason, wait five minutes, then confirm. Extension and override limits are shown in the menu bar.

Curfew is a boundary tool, not a security system. A terminal, another account, or a reboot can bypass it. It is there to make the normal choice easier: stop when you said you would.

A quick check-in, before and after work.

Choose the questions. Curfew asks them when you start work and again when curfew begins. Answer them or skip them.

01

Start with a question

Use a short prompt, rating, or mood check when you begin.

02

Wrap up

At curfew, note what happened today or what needs to wait until tomorrow.

03

Keep the record

Your journal keeps entries and ratings together. Export Markdown or JSON whenever you want.

Questions and answer types are editable in Settings. Your entries stay on your Mac.

Use your data with the tools you already use.

curfew-mcp is included with Curfew. A compatible assistant can read curfew status and reflections you choose to share. It runs locally on your Mac. Reflections are read-only; any supported request that changes Curfew waits for approval in the app.

~/.claude_desktop_config.json
{
  "mcpServers": {
    "curfew": {
      "command": "/Applications/Curfew.app/Contents/Resources/curfew-mcp"
    }
  }
}
shell
$ curfew-ctl status
phase:     warning
remaining: 14 min
locks at:  6:00 PM
warning:   T-15

curfew-ctl is included for shell scripts and dotfile hooks. It uses the same local data as Curfew.
