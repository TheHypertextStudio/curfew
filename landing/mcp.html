Curfew

Connect Curfew to an MCP client

Set up Curfew with Claude Desktop or another MCP-compatible app.

What you need

Install Curfew, then open Settings → Integrations and turn on MCP. The normal connection uses stdio and runs on your Mac.

Claude Desktop

In Curfew, open Settings → Integrations and choose Copy Claude Desktop Config. Paste it into Claude Desktop's configuration, then restart Claude Desktop.

If you need to add it yourself, place this under mcpServers in ~/Library/Application Support/Claude/claude_desktop_config.json:

{
  "mcpServers": {
    "curfew": {
      "command": "/Applications/Curfew.app/Contents/Resources/curfew-mcp",
      "args": []
    }
  }
}

After restarting Claude Desktop, ask for your Curfew status to check the connection.

Command line

curfew-ctl is bundled with the app. Run it directly, or add your own alias if you use it often.

/Applications/Curfew.app/Contents/Resources/curfew-ctl status
/Applications/Curfew.app/Contents/Resources/curfew-ctl schedule show
/Applications/Curfew.app/Contents/Resources/curfew-ctl budget
/Applications/Curfew.app/Contents/Resources/curfew-ctl reflections --days 7

What an assistant can do

  • Read your status, schedule, budget, activity, and reflections you choose to share.
  • Request an extension or a schedule change.
  • Never write reflections or request an override through MCP.

You stay in control

Curfew asks before write requests by default. In Settings → Integrations, you can keep that setting, deny requests automatically, or approve them automatically. Automatic approval lets a connected assistant make supported changes without asking again.

Advanced: local HTTP

If you need an HTTP connection, enable loopback HTTP in Settings → Advanced. It listens only on 127.0.0.1:9847, so another machine cannot reach it.

Privacy

Curfew's MCP server runs locally. Curfew does not upload the information it serves, but an MCP client may send that information to its own service. Check that client's privacy policy before sharing reflections.
